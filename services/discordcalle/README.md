# DiscordCalle Service for Jannik-Cloud

Autonomer, lebensechter Discord-Bot "Calle", basierend auf MiniMax-M3 & Image-01.

- **Image:** `git.orfel.de/jannik/discordcalle:latest`
- **Volume:** `/mnt/Jannik-Cloud-Volume-01/discordcalle` (SQLite Datenbank `calle.db`)
- **Architektur:** Reine Gateway-Verbindung (kein Port nach außen erforderlich)
